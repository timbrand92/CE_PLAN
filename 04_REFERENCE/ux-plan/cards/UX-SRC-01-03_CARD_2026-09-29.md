## What the drafter clicks and sees (as built)

1. **OF and FO:** type `OF` or `FO`, click the point. Both drop the same OVERFLOW block. The permanent tag is OF1, OF2 ... and FO1, FO2 ...
   (each counts from 1 on its own). With the project's "Number sources" switch on its default (Only when scheduled) the plan label reads
   `OF` or `FO`; on Always it reads `OF1` / `FO1`. Either way an overflow never looks like a front overflow. An imported FO takes the same symbol.
2. **Strip drain:** `CDSTRIP` (or "Strip Drain" on the Source window's type strip) asks "Specify first strip drain point", then each corner
   (Close / Undo keywords), with the live length and direction words; Accept writes the whole strip in one transaction. Strip Drain is listed
   separately from Floor Waste and is not a numbered point source.
3. **Raingarden:** `CDRG` asks for the boundary, names it RG1, then RG2 in order; a deleted number is never reused (RG1 deleted, RG2 kept, the next is RG3).
   The plan label is the same RG1.
