## 1. UX-STRUC-01 — closed-sheet writes with a notice (already built, one wording fault fixed)

1. **Already there (checked in code, not rebuilt):** Sheets sync and project setup save a drawing that is NOT open in
   AutoCAD (there is nothing open for you to save) and say so; an open drawing is never saved (QSAVE notice);
   Issue/Publish warns about an open sheet with unsaved changes (UX-STD-03, commits 0fab4a84, 8a67fc6b).
2. **Fault fixed:** the sync notice for a closed drawing was headed "Open drawing 'S01.dwg': this drawing was not open
   in AutoCAD, so CE saved ...". It now reads "Closed drawing 'S01.dwg': this drawing was not open in AutoCAD, so CE saved
   the change directly to the file on disk." Open ones read "Open drawing 'S01.dwg': ... use QSAVE". Same for support
   drawings and the shared title xref.
3. **What the drafter sees:** the same warning list at the end of Sheets sync; only the first words change. On by default (wording only).

## 2. UX-STRUC-03 — one ribbon name per tool (built, switch OFF by default)

1. **What you click:** with the switch on, a tool that has several typed names shows ONE ribbon button. The other names
   still run exactly as before when typed (Escape, Undo, save/reopen: unchanged, it is the same command).
2. **Ten buttons drop off, seven tools keep one each:**
   1. CL (drops CENTERLINE, CENTRELINE, CLINE)
   2. FFL (drops FFLMARKER, FLMK)
   3. RB (drops REBAR)
   4. SCAB (drops SCABBLE)
   5. COPYM (drops CEMCOPY)
   6. EXCELCAPTURESELECTION (drops EXCELMAPFLOOR) and EXCELCAPTUREAREA (drops EXCELMAPFLOORAREA)
3. **Read from source, all run the same code.** AB, ABS, BB, BEXT and RBL groups need nothing: the registry already shows
   each as one entry at run time (the card's "double display" does not exist in the merged registry).
4. **Left out on purpose, need Tim:**
   1. SDS/TDS, SDS1/TDS1, STS1/TTS1, SC1/TC1: a tie on length, and the code marks the T names as the deprecated ones
      (typing TDS prints a notice pointing at SDS). The card recommended the T names. **Recommendation: keep the S names.**
   2. CL1/PCL and CR1/PCR (both labelled "Column Tag"): the source shows they place DIFFERENT tags (prefix C versus PC).
      They are not duplicates; the card's list is wrong on these two.
   3. THC/BTHC/THCL/THCR, PFC group, SFC group, the "over" sets: card Open question 1, unanswered.
   4. MOVEROT/MR, COPYROT/CR (TF-01), CESTRUC/CE_STRUC_SUITE (own slice).
   5. EXCELCAPTURE... is longer than EXCELMAPFLOOR; the card chose it to match the other Excel commands, against the plain "shortest" rule. Tim to confirm.
5. **Switch:** Settings file key `CommandHub.OneNamePerTool` (default false). Shipping ribbon and the unified-host ribbon both obey it.
   The Settings page tick box is a window: Codex builds it later.
6. **Not done:** Help, the command palette and CEPALETTE search still list every name.

## 3. UX-STRUC-02 — families (Beam done, switch OFF by default; the rest not started)

1. **Beam ▾ (built, shipping ribbon only):** the big Beam button becomes a split button. Click the face: draws the last
   beam type used (Regular the first time). Click the arrow: Regular / Lower / Special / Offset (commands 1, 2, 4, 5,
   each still exactly once on the ribbon, moved out of "Beam Drafting"). The last pick is a per-user setting
   (`CommandHub.LastBeamPick`), not stored in the drawing. A failed settings save never stops the beam command.
2. **Switch:** `CommandHub.BeamFamilyDropDown` (default false).
3. **Not built:**
   1. Text ▾ (size + compass pad) is UX-STRUC-08 and needs a window.
   2. Tag ▾ (smart tag) is UX-STRUC-04/09.
   3. Hatch picture gallery is UX-STRUC-07 (pictures + gallery).
   4. Beam family on the unified-host ribbon: its Structural copy of CE_SHARED cannot draw a drop-down with memory. Needs the CE_SHARED upgrade (slice 5 of the ribbon card). Stopped there.
4. **Not built either:** UX-STRUC-05 (Legacy sort), diagnostics hiding, CESTRUC retirement (would hide or retire visible items).
