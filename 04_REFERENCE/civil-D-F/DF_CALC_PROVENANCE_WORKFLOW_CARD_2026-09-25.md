## 3. Where a value may come from

1. **Rating report:** Blue Factor is the current first route; STORM remains for older jobs. Record report type and the actual catchment/area read. A report is not proof of a drawn connection. Never import a past computations sheet as fresh calculation input.
2. **Drawing:** Pipes, pits, tanks, dimensions, levels and destination paths come only from identifiable drawn objects or a drafter's explicit choice. A crossing alone does not establish a connection. If a path stops, report where it stops.
3. **Rainfall:** Prefer the job's recorded 7 × 7 coefficients with location and source. Show any office fallback by name and as needing attention. A coefficient block and its source stay with the job on save/reopen.
4. **Settings and council:** Show the Settings value and the council field that replaced or constrained it, with council name, source passage and source status. If the field has no verified passage, say so; “council selected” is not a citation. A typed PSD stays typed until an actual rulebook value is used.
5. **Calculation and manual choice:** Derived Q, SSR, storage and orifice figures state their contributing figures. Keep a drafter's accepted override separate from a result calculated from the drawing. Unknown has no numerical stand-in. The review, sheet and plan output use the same units and rounding rules.
