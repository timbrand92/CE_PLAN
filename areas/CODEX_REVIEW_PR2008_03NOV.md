1. **P2 — preserve a valid identity transform.** `ScreenWorkAreas` obtains `CompositionTarget.TransformFromDevice` at lines 102-104, but `if (fromDevice.IsIdentity)` at line 105 replaces a perfectly valid 100% transform with the primary display's ratio. `TryGetOwnerBounds` at lines 334-342 retains that same valid identity transform. Consequently, `ApplyPreferredWindowSize` compares the owner's centre against monitor rectangles in different coordinate units at lines 280-281. This is a specific defect in the new fallback, beyond the general mixed-scaling limitation already acknowledged in the log.
2. **Concrete reproduction:** primary monitor 3840 by 2160 pixels at 150%; adjacent secondary monitor starts at x=3840 and is 1920 by 1080 pixels at 100%, with a 1040-pixel usable height. Given a window source with a valid identity transform, an owner centre at (4800,520) remains (4800,520). The new fallback changes the secondary usable rectangle to (2560,0,1280,693.333). That rectangle cannot contain the centre, so `ChoosePositionArea` returns the primary work area. A 900 by 600 minimum window fits the real secondary screen but is sent away from it.
3. **Executed proof and its limit:** invoked the actual compiled net48 `ChoosePositionArea` method by reflection, using the rectangles produced by the new fallback: returned primary (0,0,2560,1400). Positive control with the valid identity transform retained: returned secondary (3840,0,1920,1040). These are synthetic coordinate inputs to the production helper, not a real two-monitor or Win32 enumeration test. No AutoCAD window was opened.
4. **Required correction:** distinguish an absent presentation/composition source from a present source whose transform is identity; retain the latter. Keep the owner point and monitor rectangles in one coordinate space. Add a regression covering a valid identity transform on a 100% secondary display with a scaled primary, plus a missing-source control. The existing tests supply ready-made rectangles and cannot catch the conversion error. Then verify the actual window on mixed-scale displays.
