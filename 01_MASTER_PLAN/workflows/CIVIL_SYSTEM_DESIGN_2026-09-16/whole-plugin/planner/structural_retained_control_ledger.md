# Structural retained-control ledger

**Source-preservation ledger.** This records each non-theme Structural XAML surface and its controls as found in the current source, plus code-created dialog routes and contextual/grip/ribbon evidence. It preserves actions for later review; it does not say those controls are current, safe, visible, functional or accepted in AutoCAD.

- **Surface count:** 47 non-theme Structural XAML files were scanned. This matches the bounded whole-plugin source inventory count supplied by root. Three theme-resource XAML files are deliberately excluded because they are not user surfaces.
- **Editable control** includes text, choice, check, radio, list and grid controls. **Actions/navigation** includes buttons, menu items and tabs. Name, content/header/text and click/command binding are retained where expressed in XAML.
- Full declared command coverage: [structural_source_command_window_ledger.md](structural_source_command_window_ledger.md). Configured prompt/output wording: [structural_configured_field_action_manifest.md](structural_configured_field_action_manifest.md). Workflow purpose: [structural_workflow_cards.md](structural_workflow_cards.md).
- Root owns shared project, settings, Manager, sheets/issue and AI behaviour. W1/W9/W10 rows are interface preservation, not competing designs.
