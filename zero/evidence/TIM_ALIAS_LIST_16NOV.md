## What the planning chat reads from it (its reading, not Tim's words)

1. Every command has a real full name that is a plain word (Copy, Trim, Offset), and a short name of one to three letters.
2. The short name is the first letter of the word, or the first two when the first is taken (C Copy, Ch Chamfer, Ci Circle).
3. The short names live in one office list that the office edits itself.
4. This list differs from AutoCAD's standard one (here C is Copy, E is Extend, Pp is Pedit, WT is a wall tool). So a new name must be checked against THIS list as well as AutoCAD's 241. From the draft: WT clashes with the wall tool; PP (today's civil pit command) clashes with Pedit; Q, C are already taken here.
