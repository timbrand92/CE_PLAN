# R-00 audit, Structural: engineering numbers built into the code

**Fri 9 Oct 2026, 09:52 Melbourne (PC clock). Headless run 3, desk plan/03. Code reading only.** Read at the installed Structural release `origin/claude/rel-20261009f` (9babe787), folders `Modules/Structural` and `Modules/Structural.DesignCore`, through `git archive` into a scratch folder. Nothing was built, run, opened in AutoCAD or changed. None of this has been seen in AutoCAD.

Tim's rule R-00: every engineering value lives on the Settings page, nothing built into the code. "Settings page" below means the `CESETTINGS` window. "In the file only" means the value already has a name in `CS_Settings.json` but no box on the `CESETTINGS` window, so a drafter can only change it by editing the file.

## FOR TIM

**The answer.** The code holds **at least 64 engineering numbers or lists** that reach something a drafter sees. **24 of the top 40 have no Settings name at all.** 6 more have a name in the settings file but no box on the Settings page. 8 have a Settings name that the command ignores, or that covers only part of the job. 1 sits in a separate data file installed with the plugin. Only 1 of the top 40 is properly on the Settings page today.

**The five that matter most on a real job.**

1. **Pad footing size: 600 is offered for every new pad mark and drawn for any old pad with no recorded size.** There is no Settings box for it. Strip and beam widths (300) and the screw pile size do have Settings names, but only in the file.
2. **Footing size or depth over 10 m is refused outright.** CE says "Value must be 10000 or less." and asks again. That is a hard block, and your R-27 rule says warn, don't block. The 3 m "exceeds typical range" question is also built in.
3. **The member schedule writes DS1 as "2 No 90 x 45 F17 KDHW DOUBLE STUDS" and TS1 as "3 No 90 x 45 F17 KDHW TRIPLE STUDS".** That stud grade is fixed in the code. The C1 post is always drawn as an 89 SHS, and the C2 list is fixed at 9 sizes.
4. **The concrete windows (RCBEAM, RCRECTCOL, RCCIRCCOL, ligs) start at cover 40, a 300 x 500 beam, a 400 x 400 column and N16/N20/N12/N10 bars.** Their AS 3600 cover check (red under 20, amber under 25) is a simplified version written into the code, with no edition named. The stirrup command (STR) offers cover 30 and silently changes anything under 10 to 10.
5. **Text heights follow a 2.5 mm x DIMSCALE rule written in 23 separate places (counted as lines across 12 files).** The one Settings value for it (Label plot height, 2.5) is read by only two commands. Tie-down, pump pit, bored pier and subfloor labels are a fixed 100 units, so at 1:100 they print about 1 mm high. I think that is too small, but nobody has looked.

**Standards versus office habit.** Five of the top 40 are standards tables that must be cited with an edition before they are trusted: AS 3600 cover (14), AS 3600 bar spacing (15), the AS/NZS 4671 bar table with AS 3600 laps (19), the AS 2870 founding note (33), and the starter bearer span table, which is not checked against AS 1684.2 (40). Two more lean on a standard without citing it: the AS 4055 wind steps (32) and the lig hook shapes (39). The rest are office habits.

**Bracing has no capacities or factors in the code at all.** CE only adds up brace lengths against a required length you type in. Nothing is calculated, so nothing needs moving.

**What I did NOT check.** Nothing in AutoCAD. Nothing in Civil or Manager. I did not open the hatch presets, the line styles, the full checklist templates, Markup AI or the two LISP files. Layer colours are counted as one group, not one by one.
