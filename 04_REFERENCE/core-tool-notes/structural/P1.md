# TOOL NOTE: Purlin marker (P1)

**Core since:** not yet
**Build this note describes:** Structural 1.0.126 (installed code, commit 8de95c34)

---

## 1. What it does

1. **Places a purlin marker across one roof bay:** the same marker block as R1 (RAFTER-JOISTV2), tagged P1, on layer PURLINS.
2. **Takes four picks** (left, right, top, bottom), asks for the tag text, then asks whether to apply a purlin lap.
3. **Is R1's code** with a lap question added. See the R1 note for the picks.

## 2. What it changes in the drawing

1. **One marker block on layer PURLINS** (colour 200, continuous), in Model space, with the tag text inside it.
2. **A lap of 1200 mm** is set on the marker when you answer Yes. The number is fixed in the code and the question does not show it.
3. **Adds layer PURLINS if the drawing has none,** before the first question. A layer already there keeps its lock, freeze and colour.
4. **Brings the marker block in** from RAFTER-JOISTV2.dwg if the drawing does not have it.
5. **Saves CE's Settings file on your PC** after each placement, to remember the tag. It does not save the drawing.
6. **Slides the marker inside the bay** (Settings "Enable auto placement", ships on) and **straightens a bay within 12 degrees** of horizontal or vertical. No line says so for either.

## 3. What it will not do

1. **Refuses before it asks anything:** read-only drawing, layout tab ("... so CE placed no tag. Go to the Model tab, or double-click into a viewport, and try again."), REFEDIT open ("... so CE placed no tag. Close it (REFCLOSE) and try again.").
2. **Refuses a drawing in metres, centimetres or inches** with the footing-words line (see fault 7 new 4). Units "not set" count as millimetres.
3. **Bay too small or picks too close:** "[P1] Member length is too short to place the block." and the other "too close together" lines.
4. **No locked-layer check.** If PURLINS is locked it still draws there.
5. **Does not change what you pick.** Beams, walls and Xref objects are only read.
6. **Esc says nothing.** At any question it ends the tool with no marker and no line.

## 4. What it asks you, and what Enter means

1. **Four picks,** each "Pick ... [Object/Point] <Object>:" then "Select object:" or "Pick point:". Enter takes Object. Esc ends the tool, nothing placed.
2. **"Enter the tag text <P1>:"** Enter keeps the tag shown (the last P1 tag used on this PC). Esc ends the tool.
3. **"Apply purlin lap? [Yes/No] <No>:"** Enter or No: no lap. Yes: 1200 mm lap.
4. **Esc at the lap question** ends the whole placement. Nothing is drawn. It is not treated as No.
5. **No preview.** The marker is drawn straight after the lap question.

## 5. When it says Unknown or "needs checking"

1. **It never shows Unknown.** It always draws a size worked out from your picks.
2. **After "[P1] Placed P1 on layer PURLINS." it can add:** "The block did not take the size you picked: span width <n> became <m>. ... Check the size in Properties (Ctrl+1) before you rely on this span. CE changed nothing else." Check Properties before you trust the marker.
3. **The lap is not read back.** Only the widths and the depth are checked.

## 6. How to undo it

1. **U once per marker.** The code treats a typed command as one Undo step. Not proven in this note. The carpark records one Undo and Redo passing for P1 on 1.0.116 (BUG-584 extension).
2. **U does not undo** the remembered tag in the Settings file.
3. **Esc does not remove** layer PURLINS if CE added it before you pressed Esc.

## 7. Known faults

**Still open**
1. **BUG-475 (item S-09):** each pick is a question first, then a click.
2. **BUG-467:** rotated UCS. The Point option of the picks turns your click to World in the code; the open fault is the second point of AB, BB and BT1.
3. **BUG-537 (item 55):** layer name and colour 200 are fixed in the code.
4. **Not this tool:** BUG-60, BUG-426, BUG-430 and BUG-445 name a pit called P1 in Civil. They are not about this command.

**Partly fixed**
1. **BUG-584:** the marker can keep its old 2400 and 2600 widths. The code now warns (section 5). The cause is not fixed, and the check runs before the placement is committed, so whether it sees what AutoCAD finally keeps is not known.
2. **BUG-471:** in a metre, centimetre or inch drawing it refuses instead of converting.

**Already fixed in this build, not yet seen working in AutoCAD**
1. **BUG-585:** Esc at the purlin lap question still placed a purlin. The code now ends the whole placement.
2. **BUG-472:** on a layout tab or inside REFEDIT it stops with one line and draws nothing.
3. **BUG-475 (items S-10, S-14):** Esc at "Select object:" ends the tool; the code-word lines show only with detailed logging on.

**New in code, no bug covers it**
1. **The lap length 1200 is fixed and not shown** in the question.
2. **No locked-layer check** (section 3, line 4).
3. **Fixed numbers with no Settings name:** 25, 300, +200.
4. **The units refusal talks about footings,** which this tool does not draw.
5. **A depth is guessed** if the top and bottom picks are under 25 units apart (300 or a quarter of the width), with no line.
