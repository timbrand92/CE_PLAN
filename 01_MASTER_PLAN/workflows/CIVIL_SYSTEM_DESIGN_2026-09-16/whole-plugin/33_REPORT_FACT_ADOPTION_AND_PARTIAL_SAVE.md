## 4. Saving fails partway

The preferred target is a qualified owner-supported save of the reviewed related set, with a receipt identifying exact fact versions and dependencies. Atomic saving is an implementation requirement to qualify, not something this proposal claims exists. If separate persistence stages or failures can produce partial state, the screen must show it truthfully.

| Observed state | Required visible response |
|---|---|
| No adopted writes verified | Keep prior confirmed basis. Retain pending choices; do not say saved or retry until absence/readback is established if response is uncertain |
| Area B verified saved, another selected fact not saved | Show B as actual saved state, not pretend rollback to A. Show unsaved fact separately and flag affected combined basis incomplete/inconsistent until reviewed; preserve previous result evidence |
| Response lost, actual saved state unknown | Show Unknown save outcome. Read back the owner-held exact values/version/scope before retry; no duplicate adoption, history entry or revision increment |
| All selected facts saved but dependent invalidation not verified | Do not claim consumers are updated/current. Show pending reconciliation and require owner qualification of that stage; do not silently recalculate |
| Save succeeded; result regeneration failed | Governing fact remains saved. Old output stays identifiable/out of date. Retry regeneration of the reviewed current basis, not re-adopt the report |

Recovery compares intended changes with current saved facts, including concurrent edits. Retry only unchanged, verified-safe remaining stages through the same owner. Never overwrite a newer manual decision with an old pending confirmation. If a compatible group cannot be established, leave that group unresolved and continue unrelated drafting.

## 5. Source revisions and closing during review

If the PDF changes while its fact comparison is open, preserve the pending choice but invalidate the affected acceptance. Show the version actually read and the newly discovered version. Do not attach the new document hash/revision to old extracted text. If only a different fact's evidence changed, show that exact scope rather than silently approving or rejecting all rows.

If a governing fact is edited elsewhere, compare opening/current/pending values before adopting. The old confirmation cannot overwrite the newer value automatically. A job switch leaves pending review tied to its original context, under root28.

Closing follows the originating owner's actual draft resolution. Cancel before acceptance makes no governing change; closing after a verified adoption does not retract it. Explicit Discard removes remaining pending choices only, not already saved facts, source documents or completed drawing changes. Parked reviews retain their source version and must be revalidated on return; durability of parking requires owner proof.
