Tim's rule R-00: every engineering value lives on the Settings page, nothing built into the code. "Settings page" below means the Civil tabs of the Settings window (`CivilSettingsView` / `CivilGeneralSettingsView`, opened through Manager). "In the file only" means the value has a name in `CD_Settings.json` but no box on the Settings page, so a drafter can only change it by editing the file. "Ignored" means a Settings name exists but the command in question does not read it.

## FOR TIM

**The answer.** The Civil code holds **at least 85 engineering numbers or lists** that reach something a drafter sees. **20 of the top 40 have no Settings name at all.** **13 more have a Settings name that the command ignores** (it uses its own copy instead). 5 are only partly covered, and 2 have two or three different Settings names for the same thing. **None of the top 40 is fully on the Settings page today.**

**A big gap behind the gap.** More than 30 engineering values already have a Settings name, but **no box on the Settings page**: pipe roughness by material, the minimum grade by pipe size, the self-cleansing speed, the pre- and after-development runoff C, the step-iron depth, the detention pipe limits, the pit outlet speeds and the X-Civil import distances. They are "in the file only". The code shows the Civil Settings page saves 43 values; none of those is on this list.

**The six that matter most on a real job.**

1. **Roofs and paving are always C = 0.9.** `CDDESIGN` and the pump sizing both use 0.9 for every hard surface. There is no Settings name for it, although the soft-ground and pre-development C do have one.
2. **The orifice in the CDCALC Detention System tab is always sized with 0.6.** `CDDESIGN` takes the coefficient from the council profile. Every council profile says 0.6 today, so the holes agree today. Change one profile and the two screens give different holes, and nothing tells the drafter.
3. **The Pit Schedule adds "With Step Irons" deeper than 0.90 m, whatever Settings says.** `CDRULES` reads the step-iron depth from Settings (900 mm today). The Pit Schedule, and the pit size advice, have their own 0.90. Change Settings to 1000 and the schedule still writes step irons on a 0.95 m pit. The shallow-pit colour at 0.30 m has no Settings name either.
4. **Pump stations, reuse credits and the Casey orifice rule are written into the code.** The Bayside 1 in 20 storm, the 1 in 100 / 5 minute ramp check, the 50 or 80 mm rising main split at 5 L/s, the Kingston 500 L credit per 2000 L, the Manningham 0.25 factor, the Casey one-third and the Casey K of 21.9. A council change needs a new plugin build.
5. **Slab falls are fixed:** concrete 1 in 100, pavers 1 in 50, asphalt 1 in 67. `CDSLAB`, the slab flow check and the drawing check all use them. No Settings name.
6. **The long section works out pipe speeds with its own roughness list.** Cast iron and ductile iron get 0.010 there, while `CDRULES` and Edit Pipe use 0.012 from Settings. The same pipe shows two speeds.

**Labels.** Pipe label text is always 250 high and level text always 180 high. The pit cover text sits 200 off the pit (250 for detention). The automatic pipe label sits 125 off the pipe while the Settings "text offset" box says 70. None of these has a Settings box except that 70.

**Two of your rulings already touch this list.** The 3200 / 500 / 1600 X-Civil import distances moved into Settings this morning (R-00, 9 Oct), but only into the file: no box yet, and about ten other import distances next to them are still built in (item 31). INT-077 item 8 (zone-of-influence angle in Settings) and the two clearance distances are still waiting for your numbers, so nothing here invents them.

**What I did NOT check.** Nothing in AutoCAD. Nothing in Structural. I did not read Manager's own code (beyond a search for these Settings names), the LISP files, the council profile JSON (beyond its orifice coefficients), the block files or the layer colour tables. I did not open the CDCALC tabs to see whether each default is shown before a drafter types over it. Some fallbacks only bite when the Settings file cannot be read; those are marked.
