# Tim's use evidence list (started Thu 29 Oct 2026 by CE 00)

Purpose: tools that Tim's own normal work has run, taken from the CE logs by desk_jobs\ce_log_evidence.ps1, so Tim can accept them in one go instead of testing each by hand. A log line is EVIDENCE, never Tim's acceptance. A tool moves to 'TIM-CONFIRMED by use' only when Tim says so in chat (CE 03 or CE 04) for that tool or for a named group, and the desk then records his words in the ledger and the carpark.

## How it works
1. The Control Room's hourly check runs the script and adds new lines under 'Evidence' (tool, number of uses since the last line, newest time, any refusal or error sentence for that tool in his real use; no drawing names).
2. CE 03 shows Tim the list in short batches: 'accept all with no errors' or tool by tool (accept, not yet, failed).
3. Silent tools (no log line at all) are never ticked this way; only a hand check or a Codex look can prove them.
