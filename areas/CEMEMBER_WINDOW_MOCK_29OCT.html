Mock-up notes (not part of the window)
N1
Member: the 12 codes are one-click buttons. Tees and bars are left out for now. Size: typing in Find narrows the list. The figures come from the installed section list (it still says 310UB32); a dash would mean the list has no figure.
N2
4 Orientation: greyed because a UB has only one way of sitting. For a PFC, angle, Z or C the four pictures come alive and show the real section.
N3
5 Section: greyed for elevations; In front or Beyond only matters for a section.
N4
6 Points sit on: when View is Section, this row is swapped in place for a 3 x 3 grid for the base point . The row keeps the same height, so nothing moves.
N5
8 Scale: typed. It starts at the drawing's DIMSCALE.
N6
Status line under Scale: one quiet grey line when all is well, shown here. It turns amber only when there is a warning (sample in the question below). Its height is reserved for 3 lines, so nothing moves when a warning appears.
N7
Colours: only Place is solid gold. Chosen buttons, the chosen size and the chosen scale have a gold outline and a soft tint. No blue.
N8
Size: drawn at 1280 x 680 px (left 330, preview about 550, right 400). Fits 1920 x 1032 with no scrolling; only the size list may scroll inside itself.
