# TOOL NOTE: Column type picker (C2)

**Core since:** not yet
**Build this note describes:** Structural 1.0.126 (installed code, commit 8de95c34)

---

## 1. What it does

1. **Asks which column type you want** from a list of steel sizes (nine by default, 2x89SHS to 250 x 90 PFC), then places that column where you click and lets you turn it.
2. **Asks for the label** (C1, C2 ...) and places it beside the column.
3. **Links the column to a beam end** within 250 drawing units, when beam linking is on and a beam end is there.
4. **Skips the list** when the drawing's member schedule has a row marked C2. It uses the first such row, with no floor.

## 2. What it changes in the drawing

1. **The column block** on layer SUPPORT COLUMN (colour 3, made if missing), at scale 1.
2. **The label:** plain text, 200 high, turned 45 degrees, on layer SUPPORT TEXT COLUMN.
3. **A note on the column saying which label is its own.** No line on screen.
4. **When a beam end is near:** a link written into the beam's own record only. The column's own list of beams is updated only if it already has one, and a newly placed column never does (corrected 13 Nov after review `reviews\structural-tool-notes-sample.md`). One line says so. The beam is not moved.
5. **The block definition.** C2 needs the current approved SUPPORT BLOCK NEW. If the drawing has none, CE loads it. If the drawing has an older one, CE asks first (see 4).
6. **The current layer** is put back as it was.
7. **Not touched:** the member schedule record. The support file has no save call.

## 3. What it will not do

1. **Read-only drawing:** "[CE_STRUC] C2: the drawing is read-only. Save a copy you can edit first."
2. **Layout tab:** "You are on a layout tab (paper space), so CE placed no support. Go to the Model tab, or double-click into a viewport, and try again."
3. **REFEDIT open:** "A block or Xref is open for in-place editing (REFEDIT), so CE placed no support. Close it (REFCLOSE) and try again."
4. **Drawing not in millimetres:** it stops and places nothing. The line starts "This drawing's units are ...". The stop is a Settings value (Day1Units, HoldInNonMillimetreDrawings), on by default; turning it OFF lifts the stop. A drawing with units not set goes ahead (corrected 13 Nov after review `reviews\structural-tool-notes-sample.md`).
5. **Locked layer:** "Layer SUPPORT COLUMN is locked, so CE drew no support. Unlock it and try again." It checks the column layer and the label layer, and never unlocks.
6. **No frozen or off layer check.**
7. **Never redefines the block quietly.** An older block needs your Upgrade answer. Cancel places nothing.
8. **No floor.** A mark used on two floors gets the first row's size.
9. **Undo group refused:** "[CE_STRUC_SUITE] Support insertion stopped: AutoCAD could not start the required Undo group."
10. **Placing fails:** "C2: CE could not place the support, so nothing was placed. The details are in the CE log."
11. **Rotation fails:** "[CE_STRUC_SUITE] Support rotation failed; the inserted support was rolled back."
12. **Block file missing:** "[CE_STRUC_SUITE] Bundled approved SUPPORT BLOCK NEW asset is unavailable; no block was inserted."

## 4. What it asks you, and what Enter means

1. **When the schedule has a C2 row** (a line, not a question): "[CE] C2: size '<schedule size>' from the schedule, shown as '<the schedule size, shortened>'." The second value is the schedule size made shorter, not the size the block shows: if the block cannot show it, the block falls back to the command's default size and only the log says so (corrected 13 Nov after review `reviews\structural-tool-notes-sample.md`). The list is then skipped.
2. **The "Select Column Type" window** (otherwise): "Choose column type / Press 1-9, then Enter to continue." Buttons Continue and Cancel. Enter takes the highlighted size (first in the list, 2x89SHS). Cancel or the window closed: nothing placed. If the window cannot open, a command-line question appears: "C2 column type [SHS2x89/SHS100/...] <SHS2x89>: ".
3. **If the drawing holds an older support block:** "[CE_STRUC_SUITE] Existing support block definition is outdated." then "Choose [Upgrade/Cancel] <Cancel>: ". Enter is Cancel and places nothing, with no further line. Upgrade loads the approved block for new C2 columns and says "Approved support definition loaded for new C2 inserts; N existing support(s) remained unchanged." If an existing support uses a size the new block lacks, it refuses: "Existing support instances block upgrade: <handle>='<size>'".
4. **"Specify insertion point for C2: "** Esc: nothing placed. Enter: the command ends with no line.
5. **AutoCAD's own ROTATE** then runs on the new column (AutoCAD's wording, not CE's). Enter takes AutoCAD's own default, normally the last angle used; CE's code does not settle it (corrected 13 Nov after review `reviews\structural-tool-notes-sample.md`). Esc removes the column (Settings value, on).
6. **"Pick desired support text location (auto left/right/top/bottom), or Enter for auto right: "** Enter prints "Label on the right: enter its text, then click where it goes." A click prints "Label at the <side>: enter its text, it goes at the spot you picked." Esc removes the column. (If Settings "Auto detect support text side" is off, it asks "Text position [L/R] <R>: " instead.)
7. **"Enter a number to append to 'C' (or press Enter to exit): "** Typing 1 makes the label C1. Enter with nothing remembered: no label, no line, the column stays. Once a label has been typed it asks "Enter text for 'C' or <1>: " and Enter takes that text again.
8. **On the Enter route only:** "Specify insertion point: " then "Top or Bottom [T/B] <T>: ". Enter takes T.
9. **Last line:** "[CE] Support linked to nearby beam." or "[CE] No beam found nearby, so the support is not linked. Place the beam first, or run BEAMLINKMIGRATE." or "[CE] Beam linking is switched off in Settings, so the support is not linked."

## 5. When it says Unknown or "needs checking"

1. **It never says Unknown.** It either asks (the window) or takes the schedule row.
2. **"Existing support block definition is outdated."** means the drawing's block lacks states the current block has. Cancel leaves the drawing as it was.
3. **"No beam found nearby ..."** means no beam end within the link distance. The column is placed, not linked.
4. **The schedule line** names the schedule's size. If the block cannot show that size, the block takes 2x89SHS and the line still names the schedule's (see 7).

## 6. How to undo it

1. **U once** is intended. The command opens one undo group and closes it at the end. Not proven in AutoCAD.
2. **After Esc,** a layer the command created can stay behind (BUG-548), so a second U may be needed. Not proven.
3. **Not undone by U:** the label text CE remembers for the next C2.

## 7. Known faults

**Still open**
1. **BUG-501:** C2 takes the first schedule row with that mark and never asks which floor.
2. **BUG-1139:** a column placed at the end of a copied beam makes the copy take over the original beam's links. The lines the bug names are unchanged in this build.
3. **BUG-548:** after Esc, no sentence says it was cancelled, and the layer it made can remain.
4. **BUG-448 (left over):** Enter at the number question with nothing remembered ends with no sentence.
5. **BUG-532:** the support layer names are written in the code.

**Already fixed in this build, not yet seen working in AutoCAD**
1. **BUG-086:** an older support block in the drawing no longer wins quietly. CE says it is outdated and asks Upgrade or Cancel. The record calls it source-verified, awaiting deployment.
2. **BUG-576:** the window said "Press 1-8" while nine types were listed. It now counts the list (up to nine keys).
3. **BUG-437:** Enter at the text-location question means "auto right" instead of "Invalid point." (the record names C1 and TS1; C2 runs the same code).
4. **BUG-438:** the number question no longer reads a default it was never given. The cause is the record's reading of AutoCAD's library, not proven.
5. **BUG-448:** a label can no longer land beside the previous column; Esc at the number question removes the column quietly; the "Text placed" line is no longer printed early.
6. **BUG-471, 472, 473:** a non-millimetre drawing, a layout tab or REFEDIT, and a locked layer all stop C2 with one plain line.
7. **BUG-974:** a row left out of the schedule at XCLMTXT is no longer saved, so C2 asks for the size (the window) instead of using it.
8. **Layer after Esc (BUG-434, BUG-439):** the current layer comes back after Esc and after a finished C2 (the records name C1, TS1 and DS; C2 runs the same code).

**Partly fixed**
1. **BUG-537 (sizes):** the nine sizes now have a Settings list (Supports C2Sizes). It has no box on the Settings window. Layer, colour and offsets are still in the code.
2. **BUG-468:** a column with no beam link can count as a post for the level below, behind a switch that ships off and has no Settings box.

**New in code, no bug covers it**
1. **A schedule size the block cannot show** is drawn as 2x89SHS, while the line still names the schedule size. Log only. (Plan card TRUST-S3 covers it; no bug number.)
2. **"Support linked to nearby beam" can print when the link was not written.** A failed write is only logged.
3. **C2's first placement can still print AutoCAD's "Duplicate definition of block _Dot ignored."** C2 loads its block by a route that does not silence it (the C1 route does).
4. **If the block cannot be loaded,** the screen shows the raw error text: "Bundled approved support asset could not be loaded: ...".
5. **The remembered label text carries from one drawing to the next** in the same AutoCAD session.
6. **Label height 200, the 45 degree turn** are fixed in the code. (The 260 label search distance belongs to the switch commands such as SC1, not this one (corrected 13 Nov after review `reviews\structural-tool-notes-sample.md`).)
7. **A schedule saved with every row left out** does not replace the old schedule, so C2 keeps using the old one.
8. **Rotation wording:** with the rotation preview off in Settings, it still says "CE could not turn the support to the wall direction by itself. Type the rotation angle."
9. **The units stop line talks about footings** ("draws footings, labels and text", "LIST one footing").

## 8. On AutoCAD 2022 to 2024
