## Synthetic acceptance scenarios

1. New-schema drawing opened in older CE: normal drafting possible, incompatible CE writes unavailable, original unknown fields retained.
2. Repair finds stored/text invert conflict: Unknown/quarantined, both evidence sources retained; no guessed value or deleted record.
3. One module fails startup: unaffected tools remain usable, exact failure and reviewed disable/recovery route visible.
4. Update staged while drafting: loaded identity unchanged; no activation/restart. Invalid staged file leaves working installation intact.
5. Support ZIP missing one locked log: readable partial bundle and exact missing-evidence warning, never complete success.
6. Unfinished session without correlated crash artifact: Incomplete/Unknown. Confirmed crash with uncertain cause: cause remains unconfirmed.
7. Offline serious failure: bounded durable pending alert, no guessed delivery; manual local support remains usable.
