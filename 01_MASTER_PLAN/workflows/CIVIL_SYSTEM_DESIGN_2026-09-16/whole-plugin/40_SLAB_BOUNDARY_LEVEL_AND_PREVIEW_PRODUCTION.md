# Slab/site production — boundary, levels and complete preview

FOR TIM

Choose the boundary, review where each level comes from, then inspect the whole slab drainage preview. A missing level stays Unknown, and a nearby pit is only a suggestion until selected.

## Authority and scope

Concrete ordinary interaction detail under approved CV5-1–15, extending root13 and planner/civil_surface_coverage_survey_and_slab_detail. The canonical CV-05 card and full existing companion were read this continuation. This record adds mode-specific selection, level rows, child review and output gestures rather than replacing the retained engine or source qualification.

Keep familiar commands. CDSLABEDIT stays hidden until its recorded replacement gate passes. Manual CDCJ/CDSC remain; CDJOINT hidden/preview-only until engineering rules approved. No joint spacing, minimum fall, clearance, tree radius, surface algorithm or new engineering default is authorised. Existing compound/source/native-protection rules govern.

## 1. Start with one of the three approved modes

| Mode | Proposed normal interaction | Review before continuing |
|---|---|---|
| Draw new | Start CDSLAB's Draw new mode → draw the intended local boundary through the existing command prompts → return to the preserved slab review | Identify boundary geometry/units/closed validity, islands/excluded space and whether any existing route has already committed that boundary |
| Use existing boundary | Start with the selected eligible closed outline or select it on plan → show exact drawing/object identity and proposed compound scope | Existing geometry is not silently replaced, re-layered or adopted merely because highlighted. Any actual current-route layer change must be reported honestly |
| Adopt existing drawing | Select the intended existing slab evidence → compare identified boundary, existing levels/arrows/spoons/joints and candidate children | Detection is not confirmed ownership. Review exact included/excluded objects; do not sweep nearby annotation into the compound by position alone |

All three return to the same proposed working review with the mode visible. Avoid competing new/import editors and preserve existing supported command entry routes. If the route cannot establish identity, protection or usable geometry, retain the reason and let the engineer select/draw another eligible boundary; no repair by silent unlock/explode/clone.

**Current-source qualification:** the existing companion records that CDSLAB can commit a new boundary or existing-boundary layer reassignment before later control-point/dialog stages. Therefore a later Escape cannot be described as leaving no drawing change. The target preview/one-accepted-action rule remains approved, but its implementation and actual Undo boundary must be qualified by the owner. This plan does not erase that source discrepancy.

## 2. Build a level list tied to the actual plan

Select a boundary vertex/control point or an existing nominated level location. The large preview highlights that exact location. A proposed row exposes point identity/position, current FSL, pending FSL, datum, source type, source identity/revision and any manual reason. Missing level is visibly Unknown, never0.000.

| Source action | What returns to the row | What is not inferred |
|---|---|---|
| Review survey value | Named adopted surface/point and sampled evidence at the selected location, with source/version and coverage/uncertainty | A survey value is not automatically a design FSL; using it for the selected design role is explicit |
| Select pit level | Exact selected pit and level role, its value/datum/source status and relationship being proposed | Nearest pit cannot become owner, outlet or governing level. Cover/invert/other level roles cannot be silently interchanged |
| Select existing spot level | Exact local/source spot identity, interpreted value/datum and confirmation of purpose | Similar nearby text is not enough; ambiguous text/unit/source stays unresolved |
| Enter manual FSL | Typed value/datum and reason/source context where supplied, retained separately from any candidate reading | Manual entry does not alter its source report, move a pit or establish a hydraulic connection |

Switching source shows old/current/pending values before replacing a governing row. A value changed elsewhere while the review is open invalidates that affected row's acceptance; it does not erase the typed draft. Pinned levels remain identifiable against changed survey/pit evidence.

Add/edit/remove control rows deliberately, with the affected point/role visible. Removing a control row is not deletion of the survey point or pit used as evidence. The preview declares insufficient/unsupported control basis when applicable; no fall result from missing required levels. This record does not invent a sufficient-point count or triangulation rule.

## 3. Review spoons, breaklines and manual joints

| Item | Ordinary proposed review | Ownership and engineering boundary |
|---|---|---|
| Existing or new spoon | Select the exact slab and intended spoon route using its retained owner path; show proposed geometry and available level evidence together | Confirm permanent slab-child identity. Containment after moving cannot reassign it to another slab |
| Nominated breakline | Select/draw the intended local evidence and identify it in this slab's preview | A line crossing the boundary is not automatically a valid breakline or drainage connection; show unresolved/unsupported geometry |
| Manual CJ/SC | Use retained manual command, specify the intended route/placement and inspect boundary clipping/labels | User-specified joint is not an auto-designed grid. No proposed historical spacing becomes approved through the preview |
| Imported existing annotation/child | Compare known compound identity with detected candidate and preserved manual presentation | Do not adopt by nearest label, delete duplicates automatically or erase useful independent annotation during adoption |

The preview distinguishes compound-owned geometry from referenced evidence. A selected pit supplying a level is not automatically a child to move with the slab. Protect shared/foreign references from being transformed by a slab operation.

## 4. Inspect the full result before acceptance

Main keeps boundary/level-source summary and the large plan preview with visible controls for TIN, fall arrows, low points/ponding findings and warnings. These display choices inspect the same proposal; they do not independently create drawing objects. More holds the full level/source table and child identity details, while every controlling Unknown/conflict remains visible on Main.

Review concave corners, islands/excluded spaces, nominated breaklines and spoons. Triangles/arrows must not cross excluded space or ignore those constraints under CV5-7. Current minimum-fall guidance remains advisory until rulebook authority is approved; no compliance Pass from an unknown rule. A previewed ponding finding is labelled by the actual supported method, not an invented storm/flood assessment.

The final proposed output list names boundary, level/design record, TIN/hatch, arrows, spoon/joint children and any new annotations. It separately names retained manual positions and referenced objects that are not owned outputs. Accept one reviewed compound operation, with the approved single-Undo target subject to real owner/native qualification.

## 5. Ordinary change after placement

Open the reviewed qualified edit route when available; do not expose hidden CDSLABEDIT prematurely. Select the stored slab identity → change a boundary/control row or confirmed child → regenerate the full preview → compare affected arrows/low points and retained manual presentation → accept the reviewed scope.

Changing a manual arrow position alone is presentation. A later placement preview must respect that new position and cannot restore its old position; it does not make FSLs numerically stale. Changing a confirmed FSL/boundary affects the actual consuming slab result; preserve prior result/source history until deliberate regeneration.

Moving/copying the compound preserves coherent owned geometry and explicit identity under the approved compound rules. Do not silently move its external survey/pit evidence, duplicate engineering relationships or rebind children by containment. Exact copy/host/source policies require owner qualification; no new automatic hydraulic connection is introduced here.

Partial output or record-save failure exposes actual boundary, graphics, child and persistence states before any retry. It never redraws a possibly completed slab because the final save message failed. Cancel drops only the pending proposal; previously accepted immediate changes retain their actual Undo/save boundaries.

## Fictional production example and future acceptance

Use a concave local boundary with an excluded island, a known spoon, two differently purposed pit levels and one Unknown FSL. Select Use existing boundary, explicitly confirm relevant level roles and leave the missing point Unknown. Inspect the preview's unavailable fall result without filling zero. Supply a reviewed manual FSL, nominate the spoon/breakline relationship, then inspect TIN/arrows and manual-joint clipping. Cancel once and check the actual committed-state receipt; later accept the complete reviewed compound. Move one arrow manually, change one confirmed FSL, preview regeneration and confirm its position is retained. Save/reopen and inspect identity/source/child data, not just the visible hatch.
