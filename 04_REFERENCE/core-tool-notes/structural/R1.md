# TOOL NOTE: Rafter marker (R1)

**Core since:** not yet
**Build this note describes:** Structural 1.0.126 (installed code, commit 8de95c34)

---

## 1. What it does

1. **Places a rafter marker across one roof bay:** the marker block (RAFTER-JOISTV2) with a tag such as R1 and a span arrow.
2. **Takes four picks:** left and right (the bay's width), then top and bottom (its depth). Each pick starts as an Object-or-Point question.
3. **Sizes the marker to the bay,** then asks for the tag text.
4. **FJ1 and P1 are the same code** on other layers. They have their own notes.

## 2. What it changes in the drawing

1. **One marker block on layer RAFTERS** (colour 200, continuous), in Model space, with the tag text inside it.
2. **Adds layer RAFTERS if the drawing has none,** before the first question. A layer already there keeps its lock, freeze and colour.
3. **Brings the marker block in** from the file RAFTER-JOISTV2.dwg if the drawing does not have it.
4. **Saves CE's Settings file on your PC** after each placement, to remember the tag. It does not save the drawing.
5. **Slides the marker inside the bay** to miss text and walls when Settings "Enable auto placement" is on (it ships on). No line says so.
6. **Straightens a bay within 12 degrees** of horizontal or vertical to exactly that (Settings snap tolerance, default 12). No line says so.
7. **Changes your running object snap** (Nearest for the first pick of each pair, Perpendicular for the second) and puts it back at the end.

## 3. What it will not do

1. **Refuses before it asks anything:** read-only drawing ("[CE_STRUC] R1: the drawing is read-only. Save a copy you can edit first."), layout tab ("You are on a layout tab (paper space), so CE placed no tag. Go to the Model tab, or double-click into a viewport, and try again."), REFEDIT open ("A block or Xref is open for in-place editing (REFEDIT), so CE placed no tag. Close it (REFCLOSE) and try again.").
2. **Refuses a drawing in metres, centimetres or inches:** "This drawing's units are <unit>. This command draws footings, labels and text at millimetre size and cannot convert them yet, so CE has not run it. Check what the drawing is really drawn in (LIST one footing) before changing anything."
3. **Units "not set" count as millimetres.** A Settings switch (Day 1 units) turns the refusal off; no box for it was found on the Settings window.
4. **Bay too small or picks too close:** "[R1] Member length is too short to place the block." (left and right picks under 25 units apart). Also "[R1] Direction picks are too close together.", "[R1] Length picks are too close together.", "[R1] Could not resolve a stable normal direction."
5. **No locked-layer check.** If RAFTERS is locked it still draws there. AB, BB and BT1 refuse in that case.
6. **Does not change what you pick.** Beams, walls and Xref objects are only read.
7. **Esc says nothing.** Esc at any question ends the tool with no marker and no line.

## 4. What it asks you, and what Enter means

1. **"Pick LEFT beam or wall [Object/Point] <Object>:"** (as Codex recorded it). Enter takes Object. Esc ends the tool.
2. **"Select object:"** (Object). Pick a line, a polyline or something inside an Xref. Esc or Enter ends the tool, nothing placed.
3. **"Pick point:"** (Point). Your point is read in the current UCS and turned to World.
4. **The same two-step question for "Pick RIGHT beam or wall", "Pick TOP/near side" and "Pick BOTTOM/far side".**
5. **"Enter the tag text <R1>:"** Enter keeps the tag shown, which is the last R1 tag used on this PC. Esc ends the tool, nothing placed.
6. **No preview and no Yes/No.** The marker is drawn straight after the tag question.

## 5. When it says Unknown or "needs checking"

1. **It never shows Unknown.** It always draws a size worked out from your picks.
2. **After "[R1] Placed R1 on layer RAFTERS." it can add:** "The block did not take the size you picked: span width <n> became <m>. Check the size in Properties (Ctrl+1) before you rely on this span. CE changed nothing else." The marker kept an old size. Check Properties before you trust the arrow.
3. **If a block value cannot be read back, nothing is said.**

## 6. How to undo it

1. **U once per marker.** The code treats a typed command as one Undo step. Not proven in this note. The carpark records a Codex Undo and Redo of R1 passing on 1.0.116 (BUG-584).
2. **U does not undo** the remembered tag saved in the Settings file.
3. **Esc does not remove** layer RAFTERS if CE added it before you pressed Esc.

## 7. Known faults

**Still open**
1. **BUG-475 (item S-09):** each of the four picks is a question first, then a click. Unchanged in this build.
2. **BUG-467:** wrong place in a rotated UCS. R1's Point option turns your click to World in the code, and the robot passed it on 1.0.125 (record, not Codex-accepted). The open fault is in the second point of AB, BB and BT1.
3. **BUG-537 (item 55):** layer names and colours 200 and 150 are fixed in the code.
4. **BUG-494:** the carpark lists R1's Undo and Redo as "not walked" on 9 Oct. BUG-584 (14 Oct) records one Undo and Redo passing.
5. **BUG-451:** Codex could not finish the R1 steps on 1.0.109 (BLOCKED by the test, not a proven fault).

**Partly fixed**
1. **BUG-584:** the marker can keep its old 2400 and 2600 widths. The code now reads the sizes back and prints the line in section 5. The cause is not fixed, and the read-back happens before the placement is committed, so whether it sees what AutoCAD finally keeps is not known.
2. **BUG-471:** in a metre, centimetre or inch drawing R1 now refuses (section 3) instead of working. It does not convert.

**Already fixed in this build, not yet seen working in AutoCAD**
1. **BUG-472:** on a layout tab or inside REFEDIT it stops with one line and draws nothing.
2. **BUG-475 (item S-10):** Esc at "Select object:" ends the tool at once.
3. **BUG-475 (item S-14):** the code-word lines ("Direction=...") now show only when detailed logging is on.

**New in code, no bug covers it**
1. **No locked-layer check** (section 3, line 5).
2. **A depth is guessed.** If the top and bottom picks are under 25 units apart, the arrow depth becomes 300 or a quarter of the width. No line says so.
3. **Fixed numbers with no Settings name:** 25 (too short), 300 (depth), +200 (outer width).
4. **The units refusal talks about footings,** which this tool does not draw.
5. **A size that cannot be read back is never reported** (section 5, line 3).
