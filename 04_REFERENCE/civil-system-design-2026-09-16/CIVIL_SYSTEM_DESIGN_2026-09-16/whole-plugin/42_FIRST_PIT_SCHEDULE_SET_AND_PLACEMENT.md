## First schedule example

A fictional drainage drawing contains Main and Rear sets, one excluded trench grate and one manual row in Rear. The final sheet drawing reads that drainage drawing as an Xref. Open PITSCHEDULE in the final drawing, choose the source, inspect both sets and verify that the manual row remains with Rear. Place Rear only after inspecting its complete output and any continuation. Cancel the point once, then place successfully. The window closes; Main has not been silently placed, and no engineering data was written through the Xref.

## Revise the placed schedule

1. A later source revision adds a pit to Rear and changes a linked invert. Passive status reports Out of date; it does not update the table automatically.
2. Open the existing schedule's set and target space/layout. Review added/removed/changed groups and any source-changed override through root25. Refresh retains deliberate group ordering and qualified manual rows; no silent switch to a different set or drawing.
3. Preview Update against the exact existing placed instance and current insertion point. A manually edited placed cell is Needs review, not new engineering truth. A copied schedule remains inert/non-authoritative until explicitly designated.
4. Confirm current reviewed scope. Update the existing instance without delete/re-place or duplication, with the approved one-Undo target. Shared fingerprint and per-set revision determine Current/Out of date; a successful-looking table alone is insufficient.
5. Closing with pending edits follows Apply / Discard / Continue Editing. Previously accepted settings/drawing changes keep their actual boundaries. A missing source preserves the previous schedule and named finding; no zero-filled replacement.
