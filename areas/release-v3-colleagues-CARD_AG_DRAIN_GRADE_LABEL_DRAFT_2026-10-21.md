# CARD DRAFT: AG drain grade label (BUG-648), Wed 21 Oct 2026 (build/04, run 415)

**Status:** DRAFT. Not built. Written because the Command/Workflow gate says the card comes before code. Builders do not wait on Tim (INT-073): the recommended answers below are what gets built, as a DRAFT behind a switch, until Tim says otherwise.

1. **What Tim sees today:** CDAGI draws a 10 m AG drain and, at the Preview, prints "Grade: 1:50, meets the office minimum 1:100". After Accept only the dashed AG line is on the plan. No grade is written beside it. Approved UX-SURF-04 says "grade check and label".
2. **What is wanted (recommended):** one small text beside the middle of the longest run, above the line, reading left to right, same style and height as the PD tag (Settings "Surface drainage", 250 mm today). Wording: "1:50" for a run that falls towards its outlet. A run with an unknown grade gets no label (CE never guesses). A run that rises towards its outlet gets "1:50 rising" so the label never looks like a pass (BUG-649).
3. **Why this is not a quick fix:** the PD tag text is linked to its drain so erase, MOVE, COPY and renumber keep them together. A grade label needs the same link, and the renumber step today rewrites the linked text to the new drain number, which would turn "1:50" into "AGI-2". The label therefore needs its own kind of link, or the renumber step must leave a grade label alone. Neither can be proven without driving MOVE, COPY, Undo/Redo and save/reopen in AutoCAD.
4. **Recommended build (when a driver window exists):** a Settings switch "Write the grade beside an AG drain" (default ON, because the missing label is the bug; the label only appears on drains drawn after the change); the label is a second linked text (kind "grade") using the same erase/MOVE/COPY follow code as the PD tag; renumber never touches a grade label; one Undo removes drain and label together; the Settings row is a Codex window row.
5. **Open for Tim (queue for work hours, blocks nothing):** (a) is "1:50 rising" the wording he wants for a drain that falls the wrong way; (b) should existing drains get the label on a "Refresh labels" step, or only new ones. Recommendation: new drains only.
6. **AutoCAD check (Codex):** draw the 10 m AG run with outlet P2, levels 20.200 and 20.000: "1:50" sits above the middle; MOVE the drain, label moves; COPY it, the copy has its own label; Undo once removes both; save and reopen, label still linked; reverse the levels, label reads "1:50 rising".
