1. **P1 — position-only restoration can put the footer off-screen. Exact changed line: `Modules/Drainage/Services/CeWindowPlacementHook.cs:64` (activation at line 116).** The new plan sets `RestoreSize=false`, enabling fitted windows to enter the existing resolver. `CeWindowPlacement.Resolve` uses the current fitted size, then `FitOn` shrinks its returned rectangle to the remembered monitor (`Shared/CE_SHARED/Services/CeWindowPlacement.cs:116-123,166-173`). `Move` at hook lines 238-242 sets `SWP_NOSIZE`, so that smaller size is never applied. Example: same two-monitor layout, AutoCAD on a 2560 x 1440 work area, current editor 2304 x 1296, saved position (2600,100) on the adjacent 1920 x 1080 work area. The actual compiled resolver returns (2560,0,1920,1080); the real move retains 2304 x 1296, leaving 384 pixels beyond the right edge and 216 below the bottom. This is a newly enabled path for fitted editors; the helper limitation predates the PR. It is not the separately parked BUG-959 primary-monitor clamp. Fix in Civil: if the retained size cannot fit at the resolved destination, use a work area that contains that size, or refit safely before restoring. Keep CE_SHARED unchanged. Add a regression using unequal monitor work areas and assert the actual rectangle after position-only movement, not just the resolver's returned rectangle.
