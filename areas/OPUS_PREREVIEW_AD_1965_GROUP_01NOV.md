If the figures already differ, the sentence is unchanged: "Grade 1:202 ... minimum 1:200". The decision to warn (`gradeRatio - minimum > 1e-9`, line 350) is untouched, so a pipe at exactly 1 in 200 still gets no warning. This is exactly the carpark's expected behaviour, as updated after hand check H9b ("Wording fix only (show a decimal when the two figures would print the same)").
2. **A note on long figures.** The rule adds up to nine decimals until the figures differ. A pipe whose drawn length is a hair over an exact 1 in 200 (float noise, or a snap a fraction of a millimetre off) will read, for example, "Grade 1:200.0002 is shallower than minimum 1:200.0000". That is true but odd to read. It cannot be fixed by wording alone; it is the warn-or-not tolerance question already parked as BUG-1229. I do not ask for a change here, but CE 05 should note on BUG-1229 that this wording now makes the case visible.
3. **Switch.** `pipe.gradeWarningFiguresNeverMatch` (`UserSettings.cs` 1490-1498) ships ON; a missing file or group reads ON (`IsOn`, rule line 16). OFF returns early with the old `F0` figures, so the old sentence is byte for byte the same, including the em dash. That is pinned by `SwitchOff_GivesTheOldWholeNumberSentenceExactly` and the `on=false` case. Both start-up reads are pinned for three file shapes, with a whole-object "typed false changes only itself" check. No engineering value is involved. Figures use the PC's own number format, the same as before.
4. **No-hard-blocks (R-27).** No stop added; it is still a warning line.
5. **Native protection and REDO.** Text only. No write, regen, view or system-variable change; no protected file.
6. **Tests.** `Bug1235GradeWarningFiguresTests`: the "hair flatter" test would fail on the base (it reads "1:200 ... 1:200"). The exactly-1-in-200 test and the 1-in-202 test pin that nothing else moved. The settings path is a GUID folder in TEMP, deleted after each test. That line rounds the typed grade to a whole number (`GradeMismatchWarningRule.cs` 62-72 on #1919's branch).
