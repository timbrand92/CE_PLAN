## 1. Objective

Prove, entirely on synthetic/local-safe fixtures, that the future EvidenceRunner's safety envelope
works before it exists anywhere near client data: enumeration without opening files, never-hydrate
skip behaviour, resource throttling and back-off, bounded queues, checkpoint/kill/resume without
re-reading, the hard 08:15 quiesce watchdog, and disk-reserve aborts.

## 3. Runner architecture (safety-relevant core only)

Single .NET console app (LTS runtime — Codex pins the exact version on the card), standalone git
repo at `91_Tools\EvidenceRunner`, zero references to/from CE_ACAD_PLUGIN. Stage-gated by config
(`census` only in P0.5). Enumeration uses attribute-level directory iteration only (Win32
`FindFirstFileExW`-class metadata; .NET `FileSystemEnumerable` with attribute access) — **the census
code path contains no file-open API at all**, making "zero opens" a structural property, then proven
behaviourally (§5-T1). Append-only JSONL outputs; atomic checkpoint writes (temp + rename); every
record stamped `runnerVersion + configHash + fixtureManifestHash`.

## 4. Synthetic fixture specification (generated by the runner's `fixturegen` mode)

| Fixture family | Purpose |
|---|---|
| Deep tree (≥12 levels) + wide dir (10,000 entries) + ~25,000 mostly zero/small files (normal build ≤256 MB; optional after-hours scale pass ≤2 GB) | Throughput + queue-bound measurement without waste |
| Long paths > 260 chars | MAX_PATH/`\\?\` handling |
| Unicode/special names (incl. the tick character that crashed the rejected converter, emoji, combining marks, trailing spaces/dots) | Name safety — no crash, no skip-without-count |
| Zero-byte, hidden, system, read-only files; empty dirs | Attribute coverage |
| **Canary files with ACL `DENY ReadData` / `ALLOW ReadAttributes`** | The zero-open proof (§5-T1) |
| Access-denied directory (ACL) | Path-free error counting |
| Locked/open files (held by a helper process) | Sharing-violation handling |
| Junction/symlink cycles | Cycle detection — no infinite walk, reparse points never followed by default |
| `FILE_ATTRIBUTE_OFFLINE` set via `attrib +O` on sample files | Real attribute-driven skip behaviour |
| Mocked attribute unit-cases for `RECALL_ON_OPEN` (0x00040000) / `RECALL_ON_DATA_ACCESS` (0x00400000) | Placeholder logic proof where real sync placeholders cannot be fabricated |
| Name-pattern seeds (`*.bak`, `~$`, `_recovered`, `Conflicted copy`, `superseded`, `A$C…`) | Classifier smoke input for later stages |

**Recorded residual gap:** true OneDrive/SharePoint placeholders cannot be safely fabricated without
a sync provider. Mitigation: attribute-mock unit tests + real `OFFLINE`-bit integration tests now,
plus a mandatory **P1 first-contact protocol** — the real census's first bounded batch runs in
observe-attributes-only mode and reports the attribute distribution (counts only) before the skip
policy is relied on at scale. This gap and its mitigation must appear in the Role E audit report.

## 5. Acceptance test matrix (all must pass; Role E re-runs independently)

| # | Test | Pass condition |
|---|---|---|
| T1 | **Zero-open canary proof**: census over the fixture tree containing DENY-ReadData canaries plus a static source/IL content-open guard | Census completes; canaries fully indexed (name/size/dates/attributes); any attempted content read is a hard failure that cannot be swallowed; output shows no content-derived fields |
| T2 | Never-hydrate skip: `OFFLINE`-flagged + mocked recall-flagged entries | Indexed as `Unavailable` with reason code; zero content reads; counts reconcile |
| T3 | Deterministic rerun | Two runs over an unchanged tree produce byte-identical indexes (timestamps externalised) |
| T4 | Kill/resume: hard-kill mid-run at random points ×5 | Resume completes; **completed checkpointed batches do not repeat**; the unfinished batch may repeat safely; final canonical sorted record-set hash equals the uninterrupted run |
| T5 | Checkpoint atomicity: kill during checkpoint write; corrupt a checkpoint deliberately | Corrupt/partial checkpoint detected → fail-closed to last good checkpoint; no silent restart-from-zero |
| T6 | Watchdog: short-interval simulated 08:15 deadline | Clean quiesce ≤60 s: checkpoint written; process exits; whole synthetic root can be renamed away and back afterward, proving handles are released; next start resumes |
| T7 | Throttle: injected CPU/RAM pressure plus bounded real run | Back-off/pause logic passes under simulation; real run stays under 4 GB additional RAM; never allocate 6 GB to prove the hard limit |
| T8 | Disk-reserve abort: injected threshold plus configured real preflight refusal | Clean refusal/abort with checkpoint and visible reason; never fill disk; no partial junk outside scratch |
| T9 | Queue bounds: wide-dir + deep-tree | Peak memory bounded (streaming enumeration, no full-tree materialisation) |
| T10 | Error accounting: denied dir, locked files, cycle fixtures | Every error counted with reason code; **zero paths/names in the model-visible summary**; private log kept in `01_Private_Index` zone convention |
| T11 | Unicode/long-path sweep | 100% of hostile names indexed or counted as errors — nothing silently missing (totals reconcile to fixture manifest) |
| T12 | Scratch/ceiling self-limit | `fixturegen` refuses to exceed the 10 GB scratch ceiling; census refuses to start below the 100 GB C: reserve |
