3. **What you will see differently, BUG-625:** Level Update (LMU) now only changes the number of a real CE level mark (FFL, RL, SSL, NGL). If you pick an ordinary note with it, the note is left alone and the command line says how many were left unchanged. If nothing you picked is a level mark it says so and does not ask for a value. New marks are tagged; older marks are recognised by where CE draws the number (end of the tail, above the triangle).
4. **What you will see differently, BUG-1183:** if you swap whole rows of the Bored Pier Schedule and run STRSCHEDSYNC, the 300 pier stays 300 and the 600 pier stays 600. CE matches each row to its pier by the HANDLE shown on the row (or by MARK, DIA MM and VISIBILITY if the table is printed without HANDLE). A row it cannot place is left alone with a plain line. A normal edit (change one row from 600 to 300) still goes to the drawing.
5. **Both ship behind a switch that is ON:** Annotation tab tick box "Level Update (LMU) only changes CE level marks"; the pier switch (PierSyncChecksRowIdentity) is in the settings file only. Switch off = exactly the old behaviour.
