# New names for C and RC: a proposal (not decided)

**Written:** Tue 17 Nov 2026 by the planning chat. **Status: proposal only. Tim has not ruled.** Owed since D-054 ("Keep IO, rename C and RC"). Neither helper is in the first release (CE everyday helpers are out, D-097 to D-100), so nothing waits on this.

## 1. C (copy, repeating)

1. **What it is today:** AutoCAD's Copy forced to "multiple" (`reference\today\TOOLS_TODAY.md`). 355 runs recorded on 2 PCs, the most used helper.
2. **The clash:** C is AutoCAD's own short name for Copy, and it is in Tim's own alias list as Copy (`evidence\TIM_ALIAS_LIST_16NOV.md`).
3. **Proposal: retire the helper, keep typing C.** AutoCAD's own Copy already repeats until Enter when its saved setting COPYMODE is 0, which is AutoCAD's default. So C would do the same job with no helper at all.
4. **Not checked:** what COPYMODE is on the office PCs. Rule 1.9 says no chat changes a saved AutoCAD setting, so if it is not 0, Tim sets it himself.
5. **If Tim wants the helper kept anyway:** full word COPYMULTI, short name CM. CM is not in Tim's alias list. NOT yet checked against AutoCAD's own short names.

## 2. RC (rectangular revision cloud)

1. **What it is today:** a rectangular revision cloud at the office arc size; asks about object snap first. 9 runs recorded. A second copy lives in the Structural program.
2. **Proposal:** full word REVBOX, short name RV. One copy only, shared by civil and structural.
3. **Not checked:** RV against AutoCAD's own short names (it is not in Tim's alias list). The trial chat's alias check (trial 7) can confirm it in one step.

## 3. What Tim is asked, when the CE helpers are designed

1. Retire C and use AutoCAD's own Copy: yes or no.
2. REVBOX / RV for the revision cloud: yes, or another word.
