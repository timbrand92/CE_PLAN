## UX-MGR-03 - what Tim clicks and sees (when the switch is on)

1. **Open CEMANAGER.** The first tab, Status, opens on three lines: CE Manager, CE Civil, CE Structural.
2. **Each line shows** the version installed on this PC, a green, amber or red light, and one short headline.
3. **Green** = "Up to date". Nothing to do, no button.
4. **Amber** = something is waiting for you: "Update ready: 3.0.16" (button **Review update**), an update already prepared (button **View receipt**), "Restart AutoCAD to use 3.0.16" (no button), "Switched off at start-up" (button **Switch on at next start**), or "Not installed".
5. **Red** = something is broken: "Did not start" (button **Load now**) or "Files missing" (no button, the words say ask the administrator).
6. **Top of the page** one sentence, the worst light decides: "Everything is up to date." / "1 thing is waiting for you." / "2 things need fixing."
7. **Every button is a button Manager already has.** Nothing new installs, stages, approves or publishes from this page. It never touches a drawing.
8. **Escape / close:** the window closes as it does today. Nothing is saved, so save/reopen is unaffected, and there is no Undo step (no drawing change).

**Turning it on (until Codex accepts it, it is OFF).** Create `%APPDATA%\CE_SUITE\manager-switches.json` containing `{"oneGlanceStatus": true}`. Missing, blank, broken or `false` means OFF and Manager looks exactly as today. Manager only ever reads this file. A Settings-page tick box is a later Codex window job.

## Contract for Codex (window only, no XAML written here)

Bind to `PluginManagerWindowViewModel`:
1. `IsOneGlanceEnabled` (bool): show the new page in place of today's Status tab content only when true. Keep today's cards reachable (the Module and Updates tabs are untouched).
2. `OneGlanceSummary` (string) and `OneGlanceWorst` (Green / Amber / Red): the sentence and the overall light at the top.
3. `OneGlanceLines` (three items, always Manager, Civil, Structural in that order): each has `Name`, `Version`, `Colour`, `Headline`, `Problem` (empty when none), `HasProblem`, `Fix`, `FixLabel`, `HasFix`.
4. `Fix` says which existing button to raise: `LoadNow` = existing Load Now, `ReviewUpdate` = existing Review update, `ViewReceipt` = existing View receipt, `SwitchOnAtNextStart` = existing Enable on Restart (click handlers already exist in `PluginManagerWindow.xaml.cs`; the row is the line's module).
5. Colour must not be the only cue (headline words carry the state). Use CE's existing Manager palette; light and dark.
