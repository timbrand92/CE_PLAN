## Main sequence — choose, inspect, make a fixed project copy

| Step | What is shown and selected | Visible actions and boundary |
|---|---|---|
| **1. Find a detail** | Search a plain task phrase or browse a recognised category. Results show visible asset name, stable CE asset ID, discipline/category, **Approved/Candidate/etc.** status, source master/version and an actual asset preview where available. | Select an **Approved** tile to continue. Candidate opens Review/Preview only. Cancel/Escape returns to the drawing with no project copy, source relation or changed master. |
| **2. Confirm the correct asset, not merely a suggested one** | The review canvas shows the exact selected asset/version, drawing destination, current member identity if selected, or **Manual** if no member was selected. It separately shows the report/model/calculation/corpus evidence that suggested the detail and its status/revision. | **Main:** Keep selected Approved asset; choose rotation, flip or catalogue-provided variant. **More:** View source/version, suitability notes, replacement/superseded state and evidence. The drafter explicitly confirms suitability. Catalogue presence, a report/model proposal and a selected member never prove engineering adequacy. |
| **3. Review project-specific variables** | The preview lists only the selected asset's recognised variable fields: name, current/proposed value, source/provenance, units when recorded, and whether it is an attribute, dynamic property or recognised text. Approved AS1-13 examples include section number, sheet reference, member mark, level, project-specific note and schedule entry. | Edit a project field only in the preview, retaining source/Confirmed/Manual/Assumed/Unknown state. An unknown dimension, unit, scale or value stays **Unknown**; it receives no numerical default. Static approved notes remain unchanged. An unresolved placeholder stays visible and follows the existing Ready-to-Issue gate rather than being silently filled. |
| **4. Choose relation and inspect compound preview** | Preview shows native compound/detail graphics, actual asset/version, variable changes, destination location/view/scale, rotation/flip/variant and **linked selected member** or **Manual detail** relation. It names dynamic/compound objects intended to remain intelligent. | **Apply** is available only after Approved-asset and suitability confirmation. **Park** keeps the local review draft only; **Discard/Cancel** leave the drawing and master unchanged. | **5. Apply one project copy** | The operation places a fixed project copy and records stable project-detail identity plus source asset/version, field provenance and chosen relation. The approved master remains physically read-only. | The intended action has one Undo and no forced save. It creates no live master link and does not edit, synchronise, upgrade or repair the master. Actual transaction scope is future implementation/AutoCAD evidence. |

## Linked, Manual and copied detail relationships

| Situation | Proposed visible handling | What must not happen |
|---|---|---|
| Selected local member | Show the selected member's stable identity and any linked calculation/source/revision alongside the chosen asset. A calculation value can be evidence for a field; it is not proof that the asset is Approved or suitable. | Do not infer a relation from nearby geometry, label text, layer or crossing. Do not make the detail a calculator. |
| Manual detail from scratch | ST8-3 permits **Manual creation**. The header and saved relation say Manual/Unknown and retain any reason supplied by the drafter. | Do not require a fake member identity or display Manual as Approved/Checked. |
| Edit a placed project's variable or relation | Show Before / Current / Pending values, field provenance and relationship scope. A request to alter engineering-bearing text becomes a reviewed value change or an explicit visible mismatch; moving/formatting label presentation remains presentation only. | Do not silently alter embedded basis, source asset/version or member relation. An unchanged retained manual position is not a conflict merely because it is manual. |
| Copy an **existing detail** | The copy preview asks the approved ST8-10 choice: **Same member — another linked view**, **New member — select its source**, or **Independent detail — remove engineering link**. It shows source and destination identities and creates a fresh detail identity. | Do not ask these three choices when making the first detail for an already selected copied beam; that path shows the copied-beam identity or Manual. Do not silently share the wrong member identity. |

## Later master change, partial result and reopen

| Event | Proposed review result |
|---|---|
| Office library presents a new version | The existing project copy remains fixed. **More: Review version** may compare placed source/version with a Candidate current standard and shows graphic/variable/approval differences, the linked/Manual relation and manual overrides. A Candidate is compare/preview-only: it cannot Apply, and suitability confirmation cannot promote it. **Preview Update** and Apply are available only when the exact replacement asset/version is individually **Approved**, followed by explicit project-copy approval and one stated Undo scope. Keep existing, Park or Cancel remain available; no update is automatic. |
| Master becomes unavailable, superseded or approval-unknown | Existing project graphics remain available as the placed project copy. The status is a review finding; do not manufacture a new asset, re-link it live or erase the project copy. A new placement stays blocked unless its individually Approved asset is available. |
| Apply reaches graphics but not the relation, field receipt or provenance record | Report **Partial** separately for project graphics, asset/version receipt, variable-field receipt and linked/Manual relation. Review actual drawing/readback before retry; retry needs verified absence or a qualified safe-resume boundary so it cannot duplicate detail graphics. |
| Cancel/Escape during preview or reopening a Parked review | Before Apply, leave no placed project copy or master mutation. On reopen, show the saved/parked draft separately from current asset/version/evidence and mark a changed basis **Needs review** before Apply. A Cancelled project-copy draft does not make the calculation or drawing numerically stale. |
| Save/reopen | Future evidence must read project-detail identity, source asset/version, fixed-copy status, variable values/provenance, relation type and manual presentation separately. Visible linework is not proof of those records. |

## Fictitious ordinary drawing example

On a synthetic local framing sheet, a drafter selects beam **B-17** and opens Sections & Details. A report proposes a connection type, but the browser distinguishes that proposal from the selected **Approved** detail asset. The preview shows the asset version, B-17 relationship, two recognised project fields and one dimension whose source is Unknown. The Unknown value is left visible; no number is inserted. The drafter confirms suitability, chooses a permitted flip, places one fixed project copy and uses one Undo to remove it. The library master has not changed.

Later, the office library shows a newer Candidate version. The placed copy remains the original approved version. Review version displays the difference and the drafter keeps the existing project copy. On another sheet, a Manual detail is placed from the same Approved asset. Only when that existing detail is copied does the three-way member-relation choice appear. A missing approved asset blocks a fresh placement rather than producing a substitute detail.
