## Everyday edit, copy and revision

| Event | Proposed outcome |
|---|---|
| Select/edit recognised RC detail | Show Before / Current / Pending values, detail identity, selected member or Manual state, source/revision, drawing/view/level and manual label/presentation. Formatting or moving a Manual label is presentation; a field/text change that alters engineering intent requires a reviewed value edit and cannot falsely remain synchronized. |
| Existing member changes while detail review is open | Mark only that detail draft Needs review. Preserve the prior visible detail and Manual choices; Refresh, Park, Discard or Cancel affects the draft, not the member or another detail. |
| COPY existing RC detail | Show source and target drawing/view/level, fresh detail identity and relationship choice. Use same-member/new-member/independent-detail only when copying an **existing detail**. A first detail for a copied member binds that copied member or is explicitly Manual. |
| Manual detail | Manual creation stays possible. It remains visibly Manual/Unknown and never acquires a fake member, calculation or source relationship. |
| Cancel/Escape | Cancel before the confirming placement leaves no proposed detail output, relationship or source adoption. It does not promise rollback of a current source action already committed. |
| Partial / retry | Read detail graphics, member/Manual relationship, field provenance, label/presentation and inserted identity separately. Retry needs verified absence or safe resume; it never creates another detail over a possible partial output. |
| Save/reopen | Future AutoCAD evidence must separately read detail identity/geometry, field values/provenance, drawing-scale/insertion state, Manual presentation and explicit member relationship. Visible section graphics alone are insufficient. |

## Fictitious before/after

On a synthetic Level 1 drawing, the drafter starts `RCBEAM`, selects one recognised local member and uses the approved one visual RCBEAM preview. It shows all eight retained geometry choices with qualified visual names plus only supplied beam dimensions, slab position, cover, bars, ligature arrangement and source-state entries; one required field remains Unknown. The preview says **Cannot confirm complete detail** and the drafter Parks it. Nothing is placed.

Later, after a supplied/reviewed input, the one visual RCBEAM preview and drawing preview agree on one local RC beam detail. The drafter confirms one placement, then moves its label to a Manual position. Copying that existing detail requires the visible relationship choice. On Level 2, `RCCIRCCOL` starts separately under its Proposed/owner-reviewed target surface; the Level 1 detail is not selected because it looks similar. A `RCLIG` request remains a separate route and can be cancelled without changing either detail.
