### 2. Where the comma refusal applies, and whether it is a hard block

1. **Only in the New Pipe / Edit Pipe window, and only four boxes:** Diameter, first invert level, second invert level, detention Required length. Not covered (the author lists these too, REGRESSION_LOG item 6): the grade box and suggestion strip, flow, the pit windows, CDCALC and the other calculators, the Inspector palette. The Pit Schedule already has its own refusal (`linking.scheduleTypedCellsMustBeClean`, `SettingsValueCatalog.cs:102`).
2. **Could it block a legitimate entry?** (a) **Decimal-comma users:** they are told to type a point; the window never read a comma correctly anyway (item 1.1), so nothing that worked before stops working. (b) **Thousands separator:** `1,200` in Diameter is refused with both readings offered; no guess (R-12). (c) **Comma lists:** none of the four boxes holds a list. The diameter drop-down and the Recent levels list hold one figure per entry (`CdViewModel.cs:59`, `:61`; `CdViewModel.Commands.cs:46-51`), so nothing in them is split on commas. One small edge: a Recent level or a saved pipe that already holds a comma figure from an older version will now show the refusal when chosen or opened in Edit Pipe until the box is corrected. That is the right answer (the stored figure is ambiguous), but worth knowing. (d) The drawing preset buttons, which apply a preset and then start the pipe, also wait while a comma sits in a box (`CdViewModel.DrawingPresentation.cs:116-119` reads the same answer). Consistent, harmless.
3. **Hard stop or warning?** It is a hold on the Start Pipe / Save button until that one box is corrected (`Blocked(sentence, field)`, `PipeStartReadiness.cs:257`). Nothing else in the window is held, there is no lock, and correcting the box releases it at once. It is the same kind of hold as the existing "Enter the pipe diameter." and "Enter a required length above 0 mm" (`:178`, `:215`).
4. **Which it should be:** a hold, as built. Letting the pipe start would put an ambiguous figure into the drawing record that the Inspector and audit later read as ten or a thousand times too big, and guessing which reading was meant breaks "never guess" (R-12). R-27 forbids rules that restrict the design; it does not forbid refusing a figure CE cannot read. Switch OFF gives the old behaviour for anyone who disagrees.
