One window per tool

It opens filled in, shows the object as AutoCAD will draw it, then you pick after pick. A pipe opens with the size of what it joins.

No edit commands

Double-click a pit or pipe and the same window opens. Grips, MOVE, ROTATE, COPY and ERASE behave as AutoCAD's own, and joined things follow.

A figure is typed once

Every label, box, schedule row, detail and computation that shows it follows. Hold what is fixed with a padlock; the rest is worked out.

3. How it is built so it can be added to

The old plug-in grew by adding a command each time. This one has four layers, and a new need lands in exactly one of them.

WindowsAll built from the same parts: preview, cards, padlocks, status colours. A new window is assembled, not designed from scratch.
The brainFacts (a value, where it came from, held or not), sums with no fixed direction, checks. Tested without AutoCAD, so it is fast to prove.
The handsOrdinary AutoCAD objects and your own office blocks, each carrying a small hidden note. A drawing still opens and plots on a PC with no plug-in.
Office listsCouncils, pit kinds and sizes, pipe materials, lid classes, cover table, label wording, layers, hatches. Plain lists the office owns; changes reach colleagues at next start.

What stops it scattering again

A new command name is the last resort, not the first. Every fault found becomes a permanent test. The 27-test gate is the same for every tool. Every decision has a number and one home.

Where this stands today. Built and tested on a bench, not installed: the brain, seven windows, and Pit, Pipe and Long section running in AutoCAD on test copies (100 of 103 checks on the last pass). Not built yet: Job window, Inlets, Tank, Detention and Schedule in AutoCAD, the live on-cursor preview, pipe bends, metre drawings. Not settled: how a selected pit's facts show in the Properties palette (being proven), and the typed name for the Job window.
