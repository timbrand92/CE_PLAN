# BUGFIX w4 report: ONE COVER MEASURE ON EVERY SCREEN (B-096, BUG-903 follow-up), Sat 31 Oct 2026

## FOR TIM

1. **Answer:** draft PR **#1920** (B-096) is open. It sits on top of #1897 (B-022), so its base is that branch, not the release branch. It is built and unit-tested only. Nobody has opened it in AutoCAD, it is not installed, and BUG-903 stays open.
2. **What you will see differently:** the Inspector pit row, the Civil Hub, the Inspector network summary and the CDGRAPH repair report now measure cover from the ground to the OUTSIDE TOP of the pipe, the same way CDRULES does. Your example: a Road pit with 650 mm to the pit invert but a UPVC 225 pipe whose outside top is 400 mm down. Before: "OK". Now: it warns on all of those screens (Road needs 600).
3. **Plain wording on screen:** Inspector: "Cover to the outside top of pipe L1: 400 mm (min 600 mm)". Hub and summary: "Pit P1 cover is 400 mm to the outside top of pipe L1, below the 600 mm minimum". Repair report: "depth 400 mm to the outside top of pipe L1 < 600 mm min".
4. **Edge cases:** a pit whose pipes have no invert or no diameter, or a pit with no cover level, keeps the old ground-minus-pit-invert figure. If the pipe wall is not in the Settings table, cover is measured to the inside top and the line says the wall is Unknown. Nothing is ever blocked.
5. **Switch:** Settings key `checks.screensMeasureCoverToPipeTop`, ships ON. Turn it OFF and the screens give exactly the old figures.
6. **My own mistakes first:** (a) my first test run failed to start because a path with a space was not quoted; (b) the first build stopped on the missing placeholder arx (known trap), fixed with a 0-byte file; (c) one of my own tests picked the wrong finding and failed once, fixed. No wasted AutoCAD time.
7. **Hub severity unchanged:** the Hub finding is still an Info line, as it was; I did not change how loud it is. Say if you want it to be a Warning.
8. **What is NOT proven:** the Inspector pit row itself (it needs a live Inspector window) is proved only through the shared routine and a source check. Nothing was run in AutoCAD. The real-files check below shows files changed in your AppData while I worked; read item 9.
9. **Real-files check (my run could not have written settings):** no settings file changed.
