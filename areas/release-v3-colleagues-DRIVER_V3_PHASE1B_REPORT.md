## 1. What each item changed (plain words)

1. **Safety.** `session-run` now records the pid, start time and command line of the AutoCAD that ITS launch started. The clean-up acts on that exact process only. Before this, a runner that gave up could quit and kill any AutoCAD sitting on the Start tab. The clean-up also runs only when the runner holds the lock.
2. **Watchdog** (`acad_driver_v3_watchdog.ps1`, new). Starts in its own process outside the runner's process tree, so killing the runner does not kill it. Stops the runner, puts profile variables back, closes only the runner's AutoCAD (quit, quit, then end by identity), restores the settings files by hash, releases the lock, removes the copies, writes its own report. Exits quietly when the runner finishes.
3. **Calibration gate.** New `calibrate` verb and `-Expect` option. See answer 3. A click AutoCAD cannot prove is "not proven" and stops the case.
4. **The rest.** Settings title pattern; clean flag reads the guard; `{NL}` line-break token; a `#` inside quotes is kept; a case may call only 11 listed v2 verbs and cannot start a session; `_SAVE` and `.QSAVE` are refused; busy retry 60 s; locked-screen refusal; the lock is taken again between sessions; `ui-dump -Out` writes only `.json` under the run folders.
