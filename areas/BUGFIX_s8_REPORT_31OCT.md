1. **BUG-1185 cause (confirmed on the 1.0.125 line):** `TimberSubfloorService.cs` `ExecuteTagBearers` collected only each pick's end points (`TryGetEndpoints`: first and last vertex) and then called `DrawBearerLabel`, which appends a new `Line` plus the label. Fix: `labelOnly` branch calls new `DrawBearerTagText` (text only); picks are de-duplicated by handle through `SubfloorBearerTagRule.IsFirstPick`; label point is `Polyline.GetPointAtDist(Length/2)` (arc-aware) or the line midpoint. Switch `FootingWidth.RectTextCommitsOnceAccepted`. OFF takes the old path exactly (the pick, the creation and the save are in their old places).
