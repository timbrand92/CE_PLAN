# Councils register (C-)

One file per council whose stormwater requirements the office has worked to. Each file has the same ten headings so any council can be looked up the same way, and so the files can later become the dated council rows of the plugin's standards file. Re-filed from the evidence on Mon 16 Nov 2026; not confirmed by the owner and not checked against any council's current published rules.

## How to add a council

1. Take the number on the last line of this file ("Next free number"). Never reuse or renumber.
2. Copy any existing council file, rename it `C-0nn_<Council_Name>.md`, and keep the ten headings in the same order: Method; Storms and coefficients; Detention rules (underground share, tank credit, minimum orifice); Pipes, pits and details required; Notes blocks and forms; How to submit and fees; What they commonly send back; Jobs seen (codes); Conflicts between office documents about this council; Evidence.
3. Fill each heading only from a document you can name (letter, permit, guidebook, workbook, comment database, a coded job). Write "Not stated in the evidence" where nothing is known.
4. Put any limit that differs from the office's into `design\LIMITS.md` under the matching L-number, naming this council as the source.
5. Add the council to the list below and move "Next free number" on by one.
