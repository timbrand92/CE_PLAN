## C. Approved planning direction and representative acceptance

The shared asset/settings direction controls the editor:

- Changed defaults/configuration do not alter existing drawing objects without reviewed Preview, Apply and Undo.
- Missing styles use a repair preview rather than overwriting working standards.
- Only individually approved assets govern appearance. A seed/default style is a candidate, never a blanket visual authority.
- Label content remains display/presentation data. It cannot alter a pit/pipe’s engineering record, source authority, connection, calculation or issue state.

| Future scenario | Required evidence before a future acceptance claim |
|---|---|
| Add/edit/delete then Close/Escape | Reopen from the actual settings file shows unsaved mutations absent; current drawing labels unchanged. |
| Save with file unavailable | Result clearly distinguishes in-memory change, persisted change and failed/unknown persistence. Subsequent Apply All cannot imply style persistence succeeded. |
| Select another visible style | User can see whether selection is preview-only or becomes active through a separate deliberate action. It must not silently change active output. |
| Delete active style | Preview/result names the replacement active style before saving; cancellation does not quietly switch label production. |
| Apply All in drawing with qualifying and manual/non-qualifying labels | Preview scope/old/new/reason; confirmed action affects only allowed labels; manual/pinned text and protected/Xref/REFEDIT content are preserved; one Undo and save/reopen are checked. |
| Pipe-only labels | Result does not claim Apply All refreshed pipes when current source only walks pit cover/IL attachments. |
| Failure after a counted update and before Commit | Result reports attempted count separately from committed drawing result; it does not claim rollback or success without a transaction/drawing readback. |
