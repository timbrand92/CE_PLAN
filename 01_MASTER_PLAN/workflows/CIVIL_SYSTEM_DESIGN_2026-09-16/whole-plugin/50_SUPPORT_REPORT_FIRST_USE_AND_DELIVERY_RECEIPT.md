|---|---|---|

The optional description and evidence list should fit one focused report review, with technical details expandable. Do not force a module-disable, reinstall, drawing repair or crash reproduction as the first step to report a wrong label.

## Ordinary problems and interruptions

- **Wrong drawing result:** report the selected symptom and safe existing context; leave drafting usable. A screenshot illustrates it without certifying the cause.
- **Unexpected exit:** classify prior session, correlated crash evidence and suspected component separately. An incomplete session is not automatically a crash; a crash is not automatically CE's fault.
- **Locked/missing log:** save available evidence as partial with that named omission. Do not show an empty bundle as complete success.
- **Local write failure:** keep the review/description and report actual file state. Do not queue a nonexistent or unreadable ZIP or erase a valid earlier report to make room without the approved owner contract.
- **Offline destination:** keep the local report and exact pending state. Retry must refer to that same reviewed package; changed contents require a new reviewed package identity.
- **Unknown transfer outcome:** check actual existing receipt before repeating. Repeated clicks cannot silently send several different reports under one apparent operation.
- **Close/Cancel:** discard pending report edits only as explicitly chosen; preserve known completed local-file or delivery effects. Drawing Undo cannot reverse an external file or delivery.
- **Minimal serious-failure alert:** retain SUP's deduplicated minimal notice under its separately configured authority. It neither bypasses full-report review nor proves a linked ZIP upload succeeded.
