## Proposed ordinary direct sequence

`LBW` remains a direct native-prompt route. Transient drawing preview or an existing approved surface may show the review information; this card adds no compulsory window.

| Step | Drafter action | Proposed visible boundary |
|---|---|---|
| **1. Pick an intended local wall line** | Start `LBW`; use the familiar start/end point prompts. Points may legitimately snap to Xref/protected/background geometry as read-only evidence; no foreign, protected or unsupported object is modified. | Show the two explicit points, proposed line/compound direction and source/unit state where known. A too-short or unsupported proposed local output is refused/parked; no substitute geometry is chosen. |
| **2. Review evidence before bearing status** | Inspect any Xref wall-context comparison as **Candidate** evidence, including no-match or ambiguous result. Select a cited engineering/source basis or an explicit Manual/Unknown status. | The user/engineer must explicitly confirm any load-bearing intent before a governing drawing impact. “Continue anyway” from current source is not the target engineering confirmation. Candidate/Unknown remains Park/Cancel, not an automatic classification. |
| **3. Preview the complete proposed marker** | Preview exact local scope: start/end, orientation, full block/graphic result, asset/version status, target layer/presentation, source/Manual/Unknown bearing status, current/pending relation and **output space**. Current source writes ModelSpace. | **Proposed initial route:** Apply is limited to qualified ModelSpace output; PaperSpace/hybrid coordinate use Parks for explicit output-space review. Missing/unapproved asset, Required Unknown or an unconfirmed bearing basis blocks Apply. Preview does not create/import an asset, change current layer, set a project calculation, link a nearby beam/support, or modify background/Xref geometry. |
| **4. Confirm one bounded drawing result** | Confirm only after the marker, authority/status and output scope are shown together. | Proposed receipt distinguishes graphic/block identity, asset state, source/Manual/Unknown status, drawing scope and Complete/Partial/Absent/Unknown result. It is a drawing marker receipt, not a proof of structural adequacy, a schedule update or issue decision. |
| **5. Revisit after source/revision change** | When the cited source or background changes, compare Before / Current / Pending marker status and retain any Manual confirmation. | Mark only the affected item Needs review. Do not move/re-size the marker, reclassify bearing, change a beam/support relation, or overwrite manual evidence merely because an Xref wall changes. |

## Cancel, failure, manual and reopen

| Event | Current-source fact or Proposed target boundary |
|---|---|
| Cancel at either point prompt or current wall-context question | **Source-observed:** returns before its layer/asset/insertion path; `CMDECHO` has already been set and is restored through `finally`. The proposed result has no marker, authority adoption or review receipt. Preflight/native state still requires acceptance evidence. |
| Cancel before Proposed confirmation | **Proposed:** removes preview only; no asset import, layer/current-variable change, marker, source adoption or forced save. This is not a claim that current source already has that safe order. |
| Asset unavailable / dynamic property cannot be applied | **Source-observed:** source may already have performed layer/current-variable work before asset check. A missing asset returns before insert; a false dynamic-property attempt does **not** prevent the later commit. **Proposed:** report asset/field state and inspect ModelSpace before retry. Never substitute a generic block or approximate line. |
| Partial output or later retry | **Proposed:** preserve exact points, pending authority, asset state, output space and any observed marker identity. A property failure may coexist with a committed marker, so classify Complete/Partial/Absent/Unknown from readback before retry; do not duplicate an uncertain marker or silently advance a bearing status. |
| Manual/confirmed bearing evidence | **Proposed:** retain its explicit source/Manual/Unknown status and cited revision. A manual position is presentation only; it does not become a calculation or automatic support/beam link. |
| Save/reopen and forced save | Current source calls `ForceQuickSave` after its apparent success path. Future acceptance separately proves whether any save occurred, the **ModelSpace** marker/asset identity, status/relationship persistence and the applicable Undo boundary. This card does not approve or rely on a forced save. |
