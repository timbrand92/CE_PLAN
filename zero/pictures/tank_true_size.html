Rainwater tanks drawn true to size

Tim: "we have in the past not shown water tanks to scale we need to create a block or water tank that is correct to size".

Everything on this page is drawn to ONE scale. Each white picture has its own 1 m scale bar, and a boundary with a 900 mm side setback strip (the grey hatched band). Each tank is pushed up against the boundary so its width can be compared with the strip.

Sizes were read from the makers' own size pages and sheets on 19 Nov 2026. They are the makers' nominal sizes; poly tanks vary a little with shrinkage. Plan view, long side horizontal. Height is only in the label. Kingspan's own site would not open, so the Kingspan outlines come from sellers' pages.

Shapes. No maker page said what shape a slimline tank is in plan. The rounded ends here (end radius half the width) are a stand-in, and each picture says so. Get the maker's plan drawing before the block is final. Round tanks are circles, so their shape is certain.

1. Slimline steel tanks

1,000, 2,000, 3,000 and 5,000 litres. There is no checked 3,500 L steel slimline, so none is drawn.

Steel tanks are made to order. The sizes shown are the maker's listed ones; other lengths can be asked for. Steel litres are about 90 to 93 percent of length x width x height, so litres cannot be worked out from the box.

2. Slimline poly tanks

2,000, 3,000, 3,500 and 5,000 litres. The 3,500 L has a checked size: the Rotoplus Super Shortbase.

Poly tanks are moulded, so these are fixed models. The 3,500 L comes to about 79 percent of its box volume.

3. Round tanks

2,000, 5,000 and 10,000 litres. Diameter is drawn, height is in the label. No checked round tank was found for 1,000 L or for 3,500 L.

4. The two outlines the office used before

Dashed, with no real tank behind them. On the right, each is laid over a real size (solid) from the same top corner.

How the tool will draw a tank

This is what Tim ruled: "presets fill, typing wins but the tanks need to be rounded in the same way as real life."

1
Pick a volume; the maker's sizes fill the boxes; typing over them wins
What the drafter doesPicks 3,000 L. Length, width and height fill in from the maker's size. Types over any box if the real tank is different.
The litresAlways the stated figure (3,000 L), never worked out from the box. A box of 2200 x 800 x 1860 is 3,274 L, but the maker rates it 3,000 L.
The outlineDrawn rounded, as the real tank is, at the sizes in the boxes.
Watch outThe label must say TYPED when a size has been changed, so a builder knows it is not a catalogue size.
Made to orderSteel makers build to order, so their list is only the usual sizes. Typing a different length is fine; ask the maker for the litres of that length.

Sizes are from the makers' pages as read on 19 Nov 2026. Nothing here is built into the tool.
