Three rules that replace most of the old commands. (1) Every tool is one small window that opens filled in with last time's choices, then pick after pick. (2) To change anything, double-click it: the same window opens. There are no separate edit commands. (3) A figure is typed once; every label, box, schedule and computation that shows it follows.

5. How it grows without becoming strewn again

A new variable is a line in a list

A new council, pit kind, pipe material, lid class or check goes into an office list. No new command, no new window.

A new tool uses the same parts

Same window, same preview, same padlocks, same colours, and it must pass the same 27-test gate before it reaches the ribbon.

A new group gets a named slot, not loose commands
