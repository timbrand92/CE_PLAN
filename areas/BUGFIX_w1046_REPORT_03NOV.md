# BUGFIX w1046 report: BUG-1046 (B-186), 3 November 2026

## FOR TIM

1. **What you will see differently:** on a layout sheet, CDPARTS (parts catalogue) and CDLABELSTYLE (label-style editor) now open instead of saying "cannot run in Paper Space". The same two also open while you are inside a REFEDIT. CDDIAG and CDDASHBOARD now open on a layout too (they already opened in REFEDIT).
2. **What does not change:** every command that puts something in the drawing (CD, PIT, CDPIT600 and so on) still refuses in Paper Space and in REFEDIT. The windows themselves change nothing in the drawing.
3. **Switch:** Settings, `options.officeEditorsOpenAnywhere`, ON by default. Set it false and the old refusals return exactly.
4. **Mistakes of my own:** none that cost anything. Two small tool slips (no `pwsh` or `gh` on the job's bash PATH) were fixed by calling them by full path.
5. **NOT proven:** nobody has opened this in AutoCAD. Built and unit-tested only. BUG-1046 stays open. I did not check that the two windows themselves open correctly on a layout (they are pure WPF windows and should, but that is what the robot case checks).
6. **PR:** #2005 (draft), against `claude/rel-20261102a`.
7. **Robot case that proves it (name suggested: `B186_office_editors_paper`):** open a drawing with Layout1, double-click inside to PSPACE. Type `CDPARTS`, check the command line does NOT contain "cannot run in Paper Space" and the parts window opens; close it. Type `CDLABELSTYLE`, same check; the last command-line line reads "[CDLABELSTYLE] Active label style: ...". Entity count (`SELECT ALL` count or ENTITYCOUNT) before and after is identical. Control: in the same drawing type `CD`; the line "[CE] CD cannot run in Paper Space" must still appear. Switch-off control: set `options.officeEditorsOpenAnywhere` false in the settings file BEFORE launching AutoCAD (settings are read at launch), repeat `CDPARTS` and `CDLABELSTYLE`: both print the old "cannot run in Paper Space" line. Repeat the ON case inside a REFEDIT of a local block; the line "cannot run while a reference is being edited" must be absent.
